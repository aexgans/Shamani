# Шамани

Сайт персональных мантр. Человек отвечает на семь вопросов, сайт собирает мантру
и открывает её на отдельной странице: свеча в темноте, звуки выбранной стихии,
голос читает мантру, чётки считают повторения (9 / 27 / 108).

## Как устроено

Статический сайт без сборки и без сервера — только HTML, CSS и JS.

| Файл | Что делает |
|---|---|
| `index.html`, `js/app.js` | Главная: анкета из 7 вопросов и готовая мантра |
| `mantra.html`, `js/altar.js` | Страница свечи: практика, повторения, голос |
| `js/mantra.js` | Словарь (сферы, биджа-слоги, стихии) и генератор мантры |
| `js/candle.js` | Свеча и чётки на canvas |
| `js/sound.js` | Звуки природы, синтезированные в браузере (Web Audio) |
| `video.html`, `js/video.js` | Страница с видео-практикой |
| `js/letter.js` | Форма «Получи видео на почту» в конце главной |
| `js/config.js` | Настройки: какое видео показывать, куда слать почту |
| `backend/` | Google Apps Script, который рассылает письма — см. [backend/README.md](backend/README.md) |
| `media/` | Тестовое видео и обложка |
| `css/style.css` | Все стили |

Мантра целиком хранится в ссылке `mantra.html?m=…`, поэтому базы данных пока нет.
Почту из формы принимает Google Apps Script и складывает в Google-таблицу.

## Как поменять видео

В `js/config.js`, блок `video`:

- **Встраивание (рекомендуется)** — залей видео на VK Видео, Rutube или YouTube и вставь ссылку в `embed`.
  Хостинг бесплатный, видео подстраивается под скорость интернета.
- **Файл** — положи `.mp4` в `media/` и укажи путь в `src`. Годится для коротких роликов:
  GitHub не принимает файлы больше 100 МБ, а тяжёлое видео раздувает репозиторий.

## Запуск локально

```bash
node serve.js
```

Потом открыть http://localhost:5173

## Работа вдвоём

1. Перед началом работы: `git pull`
2. Новая задача — новая ветка: `git switch -c feature/название`
3. Сохранить шаг: `git add .` и `git commit -m "что сделал"`
4. Отправить: `git push -u origin feature/название`, на GitHub открыть Pull Request
5. Второй человек смотрит и нажимает Merge — изменения попадают в `main`

Ветка `main` — это то, что опубликовано на сайте.
