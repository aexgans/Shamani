# API для нейросети

Как нейросеть забирает заявки с сайта и возвращает готовую мантру.
Нейросеть сама обращается к сайту: входящие запросы ей принимать не нужно,
поэтому она может работать где угодно — хоть на домашнем компьютере с видеокартой.

Все запросы — с заголовком `Authorization: Bearer <GENERATOR_KEY>`.
Ключ задаётся на сервере переменной окружения `GENERATOR_KEY`; локально — `dev-generator-key`.

## Цикл работы

```
POST /api/generator/next                       ← взять заявку (раз в несколько секунд)
PUT  /api/generator/jobs/<id>/files/<имя>      ← загрузить каждый файл
POST /api/generator/jobs/<id>/done             ← готово: сайт откроет доступ и отправит письмо
POST /api/generator/jobs/<id>/fail             ← не получилось: заявка вернётся в очередь
```

### 1. Взять заявку

`POST /api/generator/next` → самая старая оплаченная заявка, её статус меняется на «создаётся».

```json
{ "ok": true, "job": { "id": "SH-108302", "answers": {
  "name": "Аня", "sphere": "abundance", "release": "fear", "call": "softness",
  "element": "fire", "time": "night", "intention": "Хочу меньше тревожиться по вечерам" } } }
```

Если заявок нет — `{ "ok": true, "job": null }`, спросить снова через 3–5 секунд.
Значения ответов — ключи из `js/mantra.js` (`SPHERES`, `RELEASE`, `CALL`, `ELEMENTS`, `TIMES`).
Почту человека нейросеть не получает — она ей не нужна.

Если заявку взяли и не сдали за 30 минут, она сама вернётся в очередь.

### 2. Загрузить файлы

`PUT /api/generator/jobs/<id>/files/<имя>` — тело запроса это сам файл (не form-data).

- имя: латиница, цифры, `-`, `_`; расширения `mp4 webm mp3 m4a wav ogg jpg png pdf txt`;
- сайт показывает первое видео (`mp4`/`webm`) в плеере, первую картинку — как обложку,
  первое аудио — отдельным плеером; всё, кроме картинок, — в кнопках «Скачать»;
- повторная загрузка с тем же именем заменяет файл.

```bash
curl -X PUT -H "Authorization: Bearer $KEY" -H "Content-Type: video/mp4" \
  --data-binary @video.mp4 $SITE/api/generator/jobs/SH-108302/files/video.mp4
```

### 3. Отметить готовность

`POST /api/generator/jobs/<id>/done`, JSON:

```json
{
  "title": "Мантра для тебя, Аня",
  "lines": ["Шрим · Шрим · Шрим", "Я отпускаю страх — …", "Ом. Шанти, шанти, шанти"],
  "note": "Шрим — биджа-слог изобилия и красоты."
}
```

`lines` обязательно — это текст мантры на странице и в файле `mantra.txt` для скачивания.
После этого человеку уходит письмо со ссылкой, доступ открыт 14 дней, потом файлы удаляются.

## Пример

Рабочий пример — `tools/fake-generator.js`: заглушка, которая делает всё то же самое
с тестовым видео и синтезированной музыкой. Настоящую нейросеть проще всего подключить,
заменив в ней функцию `work()`.
